# Baseline and retained snapshots

Clean B and the retained integration code each ran `bench_index_construction --root /home/simon/source/objekte/examples/musenalm --alphabet ascii|unicode --snapshot --result-dir OUTPUT_DIR`. The resulting `index.snapshot` payload was renamed to the expected `search-core-ALPHABET.snapshot` inside its trial directory, then loaded with the candidate verifier in `SnapshotMode::Required`. The four raw sample/manifests and exact snapshot SHA-256 hashes/sizes are in `manifest.json` and per-role trial directories here.

Both roles produced 129,139,458-byte ASCII and 131,650,034-byte Unicode snapshots. Their byte hashes differ, as ordinary hash-map serialization order is not the logical contract. The payloads are about 130 MB each, so they are retained under the integration worktree's ignored `target/index-construction-experiment-revision/snapshot-payloads/` and omitted from Git; `manifest.json` names each retained path. The original run-manifest command paths point to the ignored task memory location used during generation, before payload relocation. Required loads of all four payloads under the candidate restored without any parse or rebuild, and all 194 ordered query digests matched fresh B/candidate results.

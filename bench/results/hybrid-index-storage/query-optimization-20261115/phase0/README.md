# Query optimization phase 0: measurement sanity

Base commit: `8ca2851ab8` on `integration/hybrid-index-storage`. Release query executable SHA-256: `9baebc3cbc615fd4528cbea7b9716ddbfcdf94ce2dc069ad8c85eb990695a358`. Both A and B in this control use that exact binary and the same v2 stamped store; this quantifies timing drift before any query code changes. The fixture is the existing Musenalm corpus in the integration worktree, with the same schema and workload fingerprints recorded in each run manifest.

The ABBA order ran Q001, Q008, Q042, Q143, Q167, Q175, Q177, Q194 and Q202, ASCII and Unicode, 30 repetitions, 32 workers, 16 MiB prepared cache and zero verified-result cache. Every run returned the same 18 case/profile digests. The B/A geomean of case median ratios was 0.985 for the first pair and 0.924 for the second even though the binaries were identical. Short cases show substantial session noise; small ratios alone cannot establish a speedup. `trials.json`, `summary.json`, per-run CSVs, digests, manifests and compressed individual measurements preserve the raw evidence. The previous maintenance checkpoint has three interleaved full-campaign pairs at this implementation boundary with aggregate ratio 1.015; its raw results remain in `../../maintenance-20261114/`.

`perf stat` collected process-level cycles, instructions, cache misses, page faults, elapsed time and user/system CPU time for Q006, Q007, Q187, Q202 and Q175, twice each, with five query repetitions. These whole-process counters include opening and cannot be attributed solely to query execution. The exported diagnostic plans confirm Q202 scans 133,948 records and parses them all; the other plan traces are archived beside the counters. `perf record -g` was attempted for Q006, but the host rejected recording under its performance monitoring policy; `perf-stat/Q006.record.log` records the exact error. No host security settings were changed.

The baseline is adequate for large absolute changes such as replacing Q202's full scan with an exact posting. Subsequent comparisons will use the same binary base, source fixture, cache settings, and result digests, and will report small effects with the observed noise in view.

The unchanged base passed `cargo test --workspace --locked --quiet` in the subtask worktree after the sparse checkout temporarily linked the existing Musenalm fixture for the desktop discovery test. The sparse checkout now includes just its small `.objekte` configuration; the desktop discovery test passed again without the link. `cargo clippy --workspace --all-targets --locked --quiet` completed with warnings. The repository-wide spacing check reports inherited Rust formatting drift; `cargo fmt --all` and the spacing formatter were run, and their unrelated edits were restored before this evidence-only commit.

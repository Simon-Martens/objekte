## Reproduce and limits

```bash
cargo test --workspace --all-targets
cargo run --release --example accept_musenalm -- --alphabet ascii
cargo run --release --example accept_musenalm -- --alphabet unicode
cargo run --release --example bench_musenalm -- \
  --profiles ascii-off,ascii-warm,unicode-off,unicode-warm \
  --repetitions 5 --result-dir /tmp/musenalm-final-reproduction
```

Use an unused result directory because the runner creates the raw sample file
exclusively. The saved `run-manifest.json` records exact arguments, fingerprints,
registrations, environment, and the measured revision. There is no historical
warm-cache or restore measurement at the initial C16 baseline revision; the
later C24 baseline is used for restoration. There is no additional historical
query suite. Source freshness checks rely on path, size, and modified time;
same-size edits with a restored timestamp cannot be detected. Runtime updates,
watchers, and partial repository rebuilds remain deferred; see the
[implementation guide](../../../../docs/search-core.md).

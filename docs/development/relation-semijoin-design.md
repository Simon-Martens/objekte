# Relation semijoin proof scope

TASK-07 starts after the independently checked TASK-06 evaluator is integrated. Its first planner paths may restrict candidates for positive, source-independent forward relation terms with existential semantics. Every retained source remains subject to TASK-06 exact residual evaluation. A relation candidate is approximate; it never supplies exact field evidence or a complemented answer.

The planner should compare two bounded alternatives against the current source domain. Target-first verifies distinct terminal targets using their indexes and grouped reads, then maps confirmed target IDs through the existing reverse posting. Source-restricted walks only the already filtered source slots, deduplicates reachable targets, verifies each once, and retains sources with a true witness. The choice includes target candidate work, source and target fan-out, reverse membership, and file work. Query-local memoization keys target truth by collection, slot, and typed terminal predicate identity; source-dependent right operands cannot use that memo.

Apply this restriction only to a root positive term or an AND member whose own truth is necessary for the whole expression. OR and NOT need their full three-valued domains. Universal/default array truth, positional selectors, backlinks, source-dependent comparisons, and unresolved target states remain scanner residuals until a separate proof establishes a safe restriction. In particular, an empty array can satisfy a universal predicate; `?!= 'A'` is true for `[A, B]`; two existential AND terms can use different target witnesses; and an unpositioned reverse posting cannot prove an indexed array occurrence.

Record strategy and work in EXPLAIN/analysis: estimated versus actual source/target candidates, distinct targets verified, target parses and file opens, edges visited, reverse postings visited, reuse hits, and residual evaluations. Bound target sets, pending payloads, and bitmaps with explicit resource errors rather than truncation. Test forced strategy parity and candidate supersets against the independent TASK-06 oracle, including selective source/target cases, shared targets, dangling and unavailable targets, mixed fallback records, high fan-out arrays, and multi-hop paths. A target verified for many source edges should be decoded once within the query-local reuse scope.

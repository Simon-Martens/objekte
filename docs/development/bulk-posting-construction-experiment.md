# Bulk final posting-tree construction experiment

Starting branch: `fix/parallel-index-construction`, HEAD `892f3954d4f471e2565e6bafeea180a43813bdbe`. The previous parallel index-merge experiment is already reverted. This commit changes only fresh construction of final posting dictionaries; worker-local batch indexes, source scheduling, query indexes and snapshot format remain as before.

The coordinator now moves each batch's ordinary and custom posting contributions into construction-only hash maps. Duplicate typed keys combine into one checked, shifted bitmap. At collection finalization, each field's value and array-length hash maps are consumed into the existing `BTreeMap` representation; statistics and domain checks run on those final trees. Presence, null, logical eligibility and custom completeness retain their previous contracts. No whole-batch fragments or published hash/tree variants are retained.

Rust 1.99.1's locally installed `alloc/src/collections/btree/map.rs` implements `FromIterator` by collecting and sorting input entries, then calling `bulk_build_from_sorted_iter`; `Extend` calls `insert` for each entry. The experiment uses `collect::<BTreeMap<_, _>>()` once after deduplication. This is an implementation observation for the pinned toolchain, not a stable complexity guarantee. [Upstream source](https://doc.rust-lang.org/src/alloc/collections/btree/map.rs.html).

Focused tests compare complete posting maps, coverage, null/presence, statistics, ordered ranges and facet counts with the previous incremental merge at bases 0 and 65,536, including repeated/unique keys, integer/float-equivalent keys, arrays, and empty/fallback-only contributions. A small indexed-array fixture checks query parity and snapshot restoration. `cargo test -p objekte-search-core --quiet` passed (110 unit tests, one ignored, and one integration test). `cargo clippy -p objekte-search-core --lib --tests` completed with existing warnings outside the new builder and test. The stricter `-D warnings` lint check and repository-wide `cargo fmt --all -- --check` fail on pre-existing lint and formatting drift across the core and TUI. `git diff --check` passed for the experiment files.

**Performance has not been measured for this experiment.** The [previous Musenalm build recording](../../bench/results/musenalm/parallel-index-construction-d15b689d1a/) is historical reference only and cannot establish a speedup for this change.

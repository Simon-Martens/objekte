## Result

The desktop now calculates visible capacity before querying newly published segments. It uses the existing 100-row page definition and any smaller user limit, then asks a new core `IndexView::search_added_since_bounded_with_cancellation` method for at most that many hits. Selection is bounded **before** Bytes payload and evidence materialization. The existing public `search_added_since_with_cancellation` keeps its all-delta result contract. Both methods share the same appendability and segmented search path; the bounded method requires `NonZeroUsize`, so a zero-capacity page cannot accidentally request unlimited results. At zero capacity, `can_append_added_since_with_cancellation` checks whether the query may append and advances the controller's publication cursor without a delta search or selected payload read. Count, offset, sorted, global/relation, changed-lineage, and unsupported cases retain replacement or deferred behavior. Query/open generation checks and cancellation remain in the controller and worker path. A skipped full page does not mark an incomplete result complete, enable pagination, or suppress the final exact refresh.

`WorkCounters` now distinguishes selected result payload reads and bytes from residual source verification counters, with `serde(default)` for compatibility. The new counters and a selected-payload peak allow the actual bytes plus evidence path to be tested. They do not assert that residual verification reads are page bounded.

Field choices now use one pinned `IndexView` for configured definitions and `Repository::inference_report`, which includes the completed global inference summary. Two read-only view accessors expose only those reports/definitions. The controller refreshes suggestions after `Opened` resets the UI, when construction completes, on publication and index replacement/maintenance changes, and when the collection scope or available columns change. A key of open generation, instance, revision, scope, and columns coalesces repeats. Suggestions are emitted synchronously by the controller, while obsolete worker events are rejected by the existing generation checks. The same `UiUpdate::FieldChoices` feeds text autocomplete and the builder. Inferred paths retain canonical quoting, and mixed observations do not acquire an unjustified scalar type. Inference-disabled opening remains read-only for suggestions.

## Native desktop smoke

The production binary was opened in the maintained headless Wayland session with inference enabled. A 32,769-file fixture put `extra["rare.field"]` only in `f32768.json`, well outside the first visible page. With a zero-result grid, text completion offered that path as Number; the builder offered the same path and assigned Number when selected. The builder generated `extra["rare.field"] = 42`, and after clearing the unrelated zero-match full-text input the query returned exactly `f32768.json`. The fixture was expanded to 100,001 files and reopened: the window showed 100 provisional rows while 2,048 files were indexed, then an exact count of 100,001 after completion.

# 50-query JSON filter benchmark — 2026-10-31

This is the baseline before indexed snapshot counts and null/inequality postings. See the [after-change comparison](QUERY-INDEXED-COUNTS-AFTER-2026-10-31.md).

Full `examples/musenalm` repository: 148,486 JSON records in seven collections. Each filter is unscoped, so the query API searches every collection whose schema accepts that filter. Exact match counts were requested for every query; one matching record was returned. There was no early count limit.

One release-build `Repository` handle was kept throughout. All seven in-memory bigram indexes were warmed first (726.5 ms, excluded from query times). Each filter ran once before timing, then seven timed runs in alternating forward and reverse order. Times are wall-clock medians, sorted slowest first. Host: Intel Core i9-13900K, 32 logical CPUs, 30 GiB RAM; warm OS file cache. These are local measurements, not cold-start or cross-device estimates.

`Scans` counts files opened by the query scan path; `Parses` counts JSON parses, including the returned page record. `Checks` is the time spent checking source metadata for indexed exact matches. A zero scan count can still take time when many matching files need metadata checks.

## Observations

- Broad indexed counts can be slow without parsing JSON. `exists(annotation)` takes 167.82 ms for 148,478 matches; 160.54 ms of that is source metadata checking. `pseudonym = false` and `year >= 1800` have the same pattern.
- Broad negations and field comparisons scan most of the relevant files. `annotation !~ :ignorecase('Mond')` scans 148,478 files; `created < updated` scans all 148,486.
- `year = null` matches nothing yet scans 138,876 files. Null equality is an especially clear candidate for an index plan.
- Selective exact predicates such as `fictional = true` and `year = 1800 && pseudonym = true` complete in about 0.5–1 ms. Selective array predicates vary with candidate set size.

## Reproduce

```sh
cargo build --release -p objekte-bench --bin json-query-mix
target/release/json-query-mix --repo examples/musenalm --workload crates/bench/workloads/musenalm-mix-50.json --runs 7 > /tmp/objekte-mix-50.ndjson
```

The raw run is in [results/musenalm-mix-50-2026-10-31.ndjson](results/musenalm-mix-50-2026-10-31.ndjson).
